# 输入目录

业务人员通常直接在浏览器向导上传询价表。也可以提前把 Excel 放进本目录，文件名无需固定：

```text
data/input/安装专业询价材料设备.xlsx   ✅
data/input/某某项目材料询价表.xlsx     ✅
data/input/inquiry.xlsx                ✅（也可以，但不强制）
```

向导会自动：

1. 列出本目录所有 `.xlsx` / `.xlsm` 文件；
2. 根据表头内容识别名称、规格、品牌、单位、数量和报送价等列；
3. 多个文件同时存在时，由用户在页面选择本次文件。

旧版二进制 `.xls` 不受支持，请先在 Excel 中另存为 `.xlsx`。

## 表头要求（自动识别）

每个材料 Sheet 至少需要能识别出名称列，建议同时提供规格列：

| 列 | 含义 |
|---|---|
| 材料名称 | 必填语义 |
| 规格、型号 | 推荐 |
| 单位 | 推荐 |
| 数量 | 推荐 |
| 报送价 | 可选；存在时可作为审定上限 |
| 审定不含税单价 | 可空，工具回填 |
| 品牌 | 可选 |

启动向导后，在“上传询价表”步骤选择文件并确认识表结果。业务主流程不需要运行其它命令。
