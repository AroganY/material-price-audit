# 使用指南

> **推荐完整图文教程：** [WEB_GUIDE.md](./WEB_GUIDE.md)（含真实页面截图）

主流程只有一个入口：

```bash
python -m material_price_audit serve --host 127.0.0.1 --port 8765
```

命令只负责打开向导；平台选择、上传、登录、范围、暂停/停止、下载都在浏览器完成。

## 1. 选择平台

页面只展示当前维护的五个平台：广材网、领材网、慧讯网、京东和 1688。

- 只勾选你有权访问且确实要查的平台。
- 拖动后的顺序就是搜索优先级。
- 未勾选的平台不会打开登录页，也不会参与搜索。

## 2. 上传并识别 Excel

支持不超过 50 MB 的 `.xlsx` 和 `.xlsm`。旧版 `.xls` 请先在 Excel 中另存为 `.xlsx`。文件名和表头无需固定，程序会识别常见的名称、规格、品牌、单位、数量和报送价列。

识表后先看页面预览。若名称列或规格列明显识别错误，应停止任务并调整表头别名或开启可选 LLM 识表，不能在错误列映射上继续询价。

## 3. 分站登录

每个平台独立打开登录窗口。登录完成后回到向导点击校验；历史登录只显示“上次登录过”，本次仍需复核。

登录 Cookie 保存在本机 `.browser-profile/`，不会上传到任何项目服务端。不要提交该目录或分享给其他人。

## 4. 运行询价

可以设置每条材料需要 1～10 个价格和本次试跑条数。建议先用少量数据确认网站权限与匹配效果，再在页面中改为全量。

正式价必须同时满足：

- 产品名称命中；
- 型号、尺寸、电压、功率等硬规格全部有证据；
- 联机/脱机、室内/室外等语义不冲突；
- 计价单位不冲突；
- 价格来自同一商品或同一厂家报价行。

证据不足但没有明确冲突的候选会进入“规格待核”；冲突候选直接拒绝。

## 5. 查看结果

结果 Excel 的 `询价比价结果` Sheet 包含：

- 状态和合格价条数；
- 价 1～K 的来源价、不含税参考、税口径和平台；
- 商品标题、厂家、联系人、电话、计价单位和起订量；
- 可点击的详情或报价证据；
- 待核候选及缺少的规格。

`rfq.xlsx` 收录未凑满目标价数的材料，方便继续联系供应商。

## 常见状态

| 状态 | 含义 |
|---|---|
| 已凑满 K 价 | 已获得 K 个完全匹配报价 |
| 部分命中 | 有完全匹配报价，但少于 K 个 |
| 找到候选·规格待核 | 有价格，但来源没有证明全部规格 |
| 没查到 | 所选平台均无合格报价 |
| 访问频繁 / 验证码 | 当前平台停止，避免继续刷新加重风控 |

## 调试命令

以下命令面向维护者，不是业务主流程：

```bash
python -m material_price_audit check
python -m material_price_audit check --auto-install
python -m material_price_audit parse --no-llm
```
