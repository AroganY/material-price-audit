# 样例与对照表

| 文件 | 用途 |
|---|---|
| `ecommerce-query-rewrite-template.csv` | 京东/1688 **改词对照**（阶段 1 手工验证） |

## 怎么用改词表

1. 从真实询价表抄 10～20 条进 CSV（名称、规格、单位）。  
2. `清单原词A`：直接把名称+规格拼上去（接近程序现状）。  
3. `电商口语词B`：按网购习惯改写（寸、俗称、去定额腔）。  
4. 在浏览器手搜京东/1688，勾选是否有结果、详情规格能否对上。  
5. 汇总命中率：若 B 明显高于 A，再投入改词规则/LLM。  

策略说明见 [ECOMMERCE_POLICY.md](../ECOMMERCE_POLICY.md)。
