材料询价核价，怎么用？

把施工单位报的材料单价，变成有链接依据、且不高于报送价的审定参考价。 查不到的，自动列成待询价表发给供应商。

先弄懂：能帮你干什么

你现在用工具之后
报送价偏高，只能凭经验砍 有公开价的，自动给出审定参考价 + 可点开的依据
自己搜电商、截图乱七八糟 一张结果表汇总，方便对账、存档
查不到的硬砍容易扯皮 查不到就不填，另出待询价表走书面报价
三条死规矩：
① 没有依据 → 不填审定价
② 审定价 ≤ 报送不含税单价
③ 含税挂牌价会先大概换成不含税（÷1.13）再比较
这是认质认价 / 材料询价审核底稿工具，不是代替定额套用，也不是官方信息价发布。

只记 5 步

① 放表询价 Excel
② 登录广材/慧讯/领材
③ 试跑 8 条先核对
④ 跑全表出审定
⑤ 待询价发供应商

0 开始前准备

  1. 询价 Excel：必须有一列叫「报送不含税单价」（或近似名称）。
  2. 材料站账号：广材网 / 慧讯网 / 领材网会员（公司通常已有）。
  3. 电脑已装好工具：若还没装，把本页发给信息同事，或看文末「请同事装环境」。

1 放入询价表

把你的表复制到工具目录里，并改名为：

data/input/inquiry.xlsx

打开方式：进入 material-price-audit 文件夹 → 打开 data → 打开 input → 放进去。

表里一定要有报送不含税单价。审定结果不会高于这一列。

2 登录广材 / 慧讯 / 领材

让同事或 AI 在电脑上执行下面命令，或自己在「终端」粘贴回车：

cd material-price-audit
python -m material_price_audit login --profile .browser-profile --platforms guangcai,huixun,lingcai

你会看到浏览器弹出来——用公司账号登录即可。登完回到终端按回车。

密码只在你自己浏览器里输入。不要把登录文件夹 .browser-profile 发给别人。

3 先试 8 条（一定要做）

python -m material_price_audit scrape \
  --input data/input/inquiry.xlsx \
  --output data/output/result.xlsx \
  --evidence data/output/evidence.json \
  --profile .browser-profile \
  --platforms guangcai,huixun,lingcai \
  --limit 8

跑完打开：

data/output/result.xlsx

点开工作表 「实抓汇总」：

  • 有没有审定价格？
  • 点蓝色「打开详情页」，型号对不对？
对得上 → 做第 4 步全表。
全是登录页 / 对不上 → 回到第 2 步重新登录。

4 全表核价

和试跑一样，把最后的 --limit 8 删掉再跑一遍即可。

python -m material_price_audit scrape \
  --input data/input/inquiry.xlsx \
  --output data/output/result.xlsx \
  --evidence data/output/evidence.json \
  --profile .browser-profile \
  --platforms guangcai,huixun,lingcai

5 查不到的 → 发给供应商

python -m material_price_audit rfq \
  --input data/input/inquiry.xlsx \
  --evidence data/output/evidence.json \
  --output data/output/rfq.xlsx
文件你怎么用
result.xlsx审核主表，有依据的审定参考价
rfq.xlsx发给厂家/经销商，盖章回价
怎么跟施工单位说：
「有公开依据的，审定价不高于报送价，链接见结果表； 无公开价材料请按待询价表书面报价。」

常见疑问

为什么很多材料没审定价？
因为网上没有同型号公开价（定制、人防专用等）。工具故意不瞎填，请走书面询价。

必须用广材吗？
造价材料价优先用广材/慧讯/领材。也可以再加京东、1688 对比，但工程认价仍以合同品牌为准。

会泄露账号吗？
登录在你自己电脑完成。开源时也不会上传登录文件夹。不要分享 .browser-profile。

输出仅供审核参考，最终结算以合同、签证、发票为准。
