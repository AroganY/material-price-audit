material-price-audit · OSS Guide

材料询价核价 · 操作引导

准确性优先：没有商品/信息站证据就不填审定单价。
支持 广材网 / 慧讯网 / 领材网 与京东、1688 等多平台；可用 AI Agent 初始化引导。

从这里开始 AI Agent 一句话 路径约定 README 完整教程 MD

1 安装环境（做一次）

在仓库根目录打开终端，执行：

cd material-price-audit
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m playwright install chromium
python -m material_price_audit check
看到 状态 : OK 即可继续。缺依赖时命令会打印安装提示。

2 初始化（人类 & Agent 统一入口）

python -m material_price_audit init --platforms guangcai,huixun,lingcai,jd,1688

会生成：

  • config.yaml — 配置
  • data/input/ · data/output/ — 入参/出参目录
  • data/output/AGENT_NEXT.md — 给 AI 的下一步
  • .browser-profile/ — 登录态（勿提交 Git）
python -m material_price_audit guide

3 放入询价单

将 Excel 另存/复制 到：

data/input/inquiry.xlsx

列名说明
材料名称 / 规格型号建议有，便于匹配
报送不含税单价必须 — 审定上限
审定不含税单价可空，工具回填
数量 / 单位 / 品牌建议有

4 选择平台并登录

造价推荐

  • guangcai 广材网
  • huixun 慧讯网
  • lingcai 领材网

电商补充

  • jd 京东 · 1688 批发
  • zkh 震坤行 · taobao / tmall
python -m material_price_audit platforms

python -m material_price_audit login \
  --profile .browser-profile \
  --platforms guangcai,huixun,lingcai,jd,1688
广材 / 慧讯 / 领材 搜索结果通常需要会员登录。浏览器弹出后请你本人完成登录；AI 不能替你输入密码。

5 试跑 8 条 → 全量

务必先试跑，确认登录有效且详情链接正确：

python -m material_price_audit scrape \
  --input  data/input/inquiry.xlsx \
  --output data/output/result.xlsx \
  --evidence data/output/evidence.json \
  --profile .browser-profile \
  --platforms guangcai,huixun,lingcai,jd,1688 \
  --limit 8

确认无误后再全量（去掉 --limit 8）。未命中导出：

python -m material_price_audit rfq \
  --input data/input/inquiry.xlsx \
  --evidence data/output/evidence.json \
  --output data/output/rfq.xlsx
计价：审定不含税 = min(挂牌含税 ÷ 1.13, 报送不含税)。无证据不填审定。

6 查看结果

文件说明
data/output/result.xlsx核价结果；先看「实抓汇总」
data/output/evidence.json证据链（URL / 平台 / 价格）
data/output/rfq.xlsx未命中，发给供应商

在「实抓汇总」点击蓝色 打开详情页，核对型号是否一致。

7 交给 Grok / Codex / Claude

把下面整段复制给 Agent：

请按 material-price-audit 的 AGENTS.md 协议执行。

工作目录：<本仓库根目录>

1. 运行：python -m material_price_audit init
2. 阅读终端 AGENT_GUIDE 与 data/output/AGENT_NEXT.md
3. 按 questions 一项一项问我（不要一次问完）
4. 我回答后执行 next_command；每步结束后再 guide
5. 遵守：无证据不填审定；平台由我指定；先 scrape --limit 8

默认平台建议：guangcai,huixun,lingcai,jd,1688

协议文件：AGENTS.md · 运行时引导：data/output/AGENT_NEXT.md

? 常见问题

广材一直跳登录？
正常，材料检索需会员。先 login 再 scrape。

很多行没有审定价？
正确行为。无公开价/定制件不会编造，用 rfq 询供应商。

YAML 里 1688 变数字？
写成 "1688" 带引号。

合规？
仅在你有权使用的账号下登录；遵守网站条款；输出仅供审核参考。

请勿把 .browser-profile/ 与真实项目报价提交到公开 Git 仓库。
