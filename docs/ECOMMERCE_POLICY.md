# 电商平台策略（京东 / 1688）

> 产品决策 · 2026-07-30  
> 与造价信息站（广材 / 慧讯 / 领材 / 易择）**分流**，避免「搜到零售挂牌却当成信息价」。

---

## 四条硬规矩

| # | 决定 | 默认 |
|---|---|---|
| 1 | 京东 / 1688 的价算不算「正式合格价」？ | **不算**。只进 **市场参考 / 待核**（`price_role=market_ref`） |
| 2 | 默认是否开启？ | 由用户勾选；**建议**造价站优先，电商作补充。可开「仅没查到再跑电商」（见配置） |
| 3 | 匹配标准 | 造价站：继续 strict / practical / loose。电商：即便规则判 formal，**也不得写入正式 quotes** |
| 4 | 验证码 / 限流 | **停当前站检索**；提示用户在浏览器完成验证后点继续（`LOGIN_CONTINUE`）；禁止空转猛刷 |

---

## 结果语义

| 类型 | 来源 | 结果表表现 | 能否直接当审定参考 |
|---|---|---|---|
| 正式合格价 | 广材 / 领材 / 慧讯 / 易择等，硬规格过关 | 绿 / 「已凑满」「部分命中」 | 可作参考，仍须人工复核 |
| 市场参考价 | 京东 / 1688 | 「电商参考」列 / 待核区，标注平台 | **否**，仅市场线索 |
| 候选待核 | 造价站灰区 | 黄条待核 | 人工点选后采用 |
| 没查到 | 各站均无可用结果 | 灰 / RFQ | — |

---

## 运行节奏（电商）

- 检索词更少（默认每站 ≤2 组）
- 词与词之间 **随机间隔**（默认约 2.5～5s，可配置）
- 命中 `rate_limited` / `captcha`：本会话该站熔断或等人验证后续跑
- 与造价站共用浏览器配置，但逻辑上 **不把电商 formal 混进合格价列表**

## 明确不做

- 高速全表扫京东 / 1688  
- 绕过验证码 / 伪造登录  
- 用 LLM **编造**价格  
- 电商挂牌价冒充信息价写入「合格价」主栏
